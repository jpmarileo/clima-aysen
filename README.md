# 🌊 Aysén MeteoMar

**Clima en tiempo real + Estado de Puertos en la Región de Aysén (XI Región)**

Una aplicación web ligera y útil para navegantes, pescadores y residentes de **Puerto Cisnes** y toda la Región de Aysén.

---

## ✨ Funcionalidades

- **Clima actual** en Puerto Cisnes con temperatura y velocidad del viento
- **Estado de puertos** principales de Aysén (Cisnes, Chacabuco, Melinka, Aguirre, etc.)
- **Mapa interactivo** centrado en Puerto Cisnes
- Acceso directo a fuentes oficiales:
  - SITPORT (Directemar)
  - Situación Portuaria
  - Windy (Pronóstico de viento)

---

## 🎯 Enfocado en

- Puerto Cisnes (Aysén)
- Información crítica para navegación segura
- Alertas por viento fuerte (causa principal de cierres de puertos)

---

## 🛠 Tecnologías Utilizadas

- **HTML5 + CSS3 + Vanilla JavaScript**
- **Tailwind CSS** (vía CDN)
- **Leaflet.js** (mapas)
- **Open-Meteo API** (clima gratuito)
- Totalmente compatible con **Spck Editor** en Android

---

## 📱 Cómo Usar

1. Abre el archivo `index.html` en Spck
2. Presiona el botón de vista previa
3. Usa los botones para acceder a información oficial en tiempo real
4. Actualiza los estados de los puertos manualmente según SITPORT
